# 建筑施工进度数字化管控系统

## 项目简介

建筑施工进度数字化管控系统是一个基于Vue 3 + Vite + Element Plus + ECharts技术栈开发的富客户端应用，旨在帮助建筑施工企业实现施工进度的数字化管理和监控。系统提供了全面的功能模块，包括施工进度管理、统计分析、用户管理、文档管理、远程监控和系统设置等，为建筑施工项目的进度管控提供了一站式解决方案。

## 功能特点

### 1. 施工进度管理
- 项目进度列表展示
- 进度趋势图表分析
- 进度预警和对比
- 快速操作功能（批量导入、导出模板、打印报表、进度会议）

### 2. 统计分析
- 项目进度分布图表
- 资源使用情况分析
- 成本分析和成本构成
- 质量安全问题统计
- 设备使用情况分析

### 3. 用户管理
- 用户列表和状态管理
- 角色权限控制
- 用户创建、编辑和删除

### 4. 文档管理
- 文档分类和上传
- 文档版本管理
- 文件预览和下载

### 5. 远程监控
- 视频监控管理
- 实时传感器数据显示
- 告警系统和处理

### 6. 系统设置
- 基本设置管理
- 通知设置
- 数据备份和恢复

## 技术栈

- **前端框架**: Vue 3 + Vite
- **UI组件库**: Element Plus
- **数据可视化**: ECharts
- **样式管理**: CSS3
- **构建工具**: Vite
- **包管理器**: npm

## 安装部署

- npm 6.0+

```bash
npm install
```

```bash
npm run dev
```

```bash
npm run build
```

### 5. 预览生产构建

```bash
npm run preview
```

## 核心功能模块

### 施工进度管理
施工进度管理模块是系统的核心功能，提供了项目进度的实时跟踪和管理。用户可以通过表格查看所有项目的进度情况，通过图表分析项目进度趋势，设置进度预警，并进行进度对比分析。

### 统计分析
统计分析模块提供了多维度的数据可视化功能，包括项目进度分布、资源使用情况、成本分析、质量安全问题统计和设备使用情况等。用户可以通过不同类型的图表（柱状图、折线图、饼图）直观地了解项目的各项指标。

### 用户管理
用户管理模块提供了用户的创建、编辑、删除和状态管理功能，支持角色权限控制，确保系统的安全访问。

### 文档管理
文档管理模块支持文档的分类管理、上传、版本控制、预览和下载，为项目文档的管理提供了便捷的工具。

### 远程监控
远程监控模块支持视频监控管理和实时传感器数据显示，提供了告警系统和处理功能，确保项目现场的安全和正常运行。

### 系统设置
系统设置模块提供了基本设置、通知设置、数据备份和恢复等功能，确保系统的正常运行和数据安全。

## 技术亮点

1. **响应式设计**: 适配不同屏幕尺寸，提供良好的移动端体验
2. **丰富的数据可视化**: 使用ECharts实现多种类型的图表，直观展示数据
3. **模块化架构**: 采用组件化开发，代码结构清晰，易于维护
4. **良好的用户体验**: 界面美观整洁，操作流畅，响应及时
5. **完善的错误处理**: 确保系统稳定运行，提升用户体验
6. **可扩展性**: 模块化设计，易于添加新功能和扩展现有功能
